# Otto's runtime wheels. The core harness — tasks, agents, tools, permissions,
# memory, providers — imports nothing outside the standard library, which is why
# the whole test suite runs with none of these installed.
#
# Every one of these has a pre-built wheel for macOS x86_64. Nothing compiles,
# nothing needs Rust, nothing needs Xcode. There is deliberately no torch:
# PyPI has no modern torch wheel for Intel macOS, and Otto is designed so that
# it is never needed.
